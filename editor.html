Lick Chords

Patches 28 (WAYLO_LICK_CHORD_1) and 29 (WAYLO_LICK_CHORD_2) play chords whose notes move through a melody ("lick"). Playing a note at C4 or above selects a chord position (C4=0, C#4=1, D4=2 …). Each voice has a starting position in the melody (0-indexed). The chord notes field documents which MIDI notes that maps to — it must match melody[startPos] for each voice. As position advances each voice steps forward through the melody; when it runs off the end it wraps back to the start an octave higher. Notes below C4 silently set transposition (same as CHORD_SCALE patches).

MIDI import format: Bar 1 whole notes = chord voices (actual MIDI notes with octave, sorted low→high). Everything after bar 1 = melody notes in order (any duration). Starting positions are entered manually.
