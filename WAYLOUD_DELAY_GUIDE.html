01 — Hardware

Controls

Every control is global — it acts on whichever patch is currently loaded. Nothing here needs a menu or a screen; the numbers match the diagram above.

1

Knob 1 — macro (patch-dependent)

On most patches, this is the More Beer / Zarabeth macro: it eases the patch's own modulation depth and rate up or down together. Straight up (12 o'clock) is neutral — exactly what the patch was saved with. Turn left to calm the wobble down, right to push it further.

On six specific echo/delay patches, it does something different: it drives delay time and feedback together instead, same center-neutral idea, from 0.25× up to 3× the patch's stored values. Those six are listed in Presets & slots.

2

Knob 2 — wet level

Sets the effect's wet (delayed) signal level, 0–100%. It only ever adds delay signal on top — it never touches the dry signal, which stays whatever the patch or editor set it to.

3

Button 1 — trim down

Each press scales every voice's delay time and feedback down together by another 0.1×, to a floor of 0.25× the patch's stored values. Shorter repeats, less feedback.

4

Button 2 — trim up

The mirror of Button 1: each press scales time and feedback up by 0.1×, to a ceiling of 3×. Longer repeats, more feedback — right up to self-oscillation territory near the top of the range.

Both trims reset to 1× (unmodified) whenever you change patches.

5

Encoder — three actions in one

  • Rotate — scroll through patches, one step per detent. Skips any patch you've disabled from the editor's checklist; disabled patches are still reachable by MIDI Program Change.
  • Press & release — cycles the input/output routing, one step forward each time: Stereo In/Out → Mono In/Stereo Out → Bypass → Mono In/Out → back to Stereo.
  • Press & hold (> ~0.3s) — quick-saves the current live sound to a user slot: if you're already on a user slot, it saves there; otherwise it saves to the next slot in a running rotation and advances that rotation for next time.

LEDs

LED 1 shows a color unique to the loaded patch — same patch always looks the same, so you can spot a change at a glance without reading a screen. LED 2 mirrors it at a third the brightness, except when bypass is active, when it goes solid red.

No hardware bypass button Bypass only toggles from the encoder's routing cycle (step 3 above), the editor's Bypass checkbox, or MIDI CC 64 (sustain-pedal style, ≥64 = on).
02 — Memory

Presets & slots

131 total slots: 32 factory, 99 user. Factory patches can't be overwritten from the front panel or MIDI — quick-save and editor saves always land in a user slot.

Slots 0–31

Factory

The "legend" chorus, lead-solo, swell and echo families, plus Waylochorus 1 and Waylolead 1. Fixed, read-only.

Slots 32–130

User (99)

Freely editable from the browser editor. Each can carry a custom name up to 12 characters, shown in place of the default "User NN" label.

25 of the 99

Magicstomp imports

Pre-loaded by default from a real Magicstomp patch bank, each in the same slot number it held on that bank.

The six delay-time/feedback patches

These are the only patches where Knob 1 controls delay time + feedback instead of the usual depth/rate macro — all genuine echo/delay-type imports, not chorus or modulation patches:

03 — Remote control

MIDI

Program Change selects any of the 131 slots directly (including disabled ones). Seven Control Changes reach the parameters the front panel doesn't expose on its own:

CCNameDoes

11ExpressionDry level

CC 1 and CC 2 stack multiplicatively with Knob 1 rather than overriding it — on delay-type patches they leave Knob 1's time/feedback job alone and keep working the old depth/rate macro underneath.

04 — Software

Browser editor

The full parameter set — beyond what two knobs and two buttons can reach — lives in waylo_ud_editor.html, a self-contained page that talks to the Pod over USB via WebSerial. No install, no server; it needs a WebSerial-capable browser (Chrome or Edge).

  1. Plug the Pod in over USB and open the editor page. Click Connect and pick its serial port from the browser's prompt.

  2. Adjust any of the 52 parameters, grouped as Core Mix, Delay Times, Delay Gains, Mod Depth & Rate, and Feedback & Pan — eight per-voice sliders per group.

    Changes to a loaded user slot write live; factory slots are read-only until you save them into a user slot.

  3. Save the current sound to any of the 99 user slots, with an optional name up to 12 characters.

  4. To import a Magicstomp .ub9 library file, use the Import panel: pick the file, review which patches converted, then save one at a time or use Save All to Selected Slots.

    Only four Magicstomp effect types have a WayloUD equivalent and convert: Eight Band Parallel Delay, Mod Delay, Eight Multi-Tap Mod Delay, and Symphonic. Reverb, pitch-shift, phaser, distortion and amp-sim patches have nothing to convert to and are skipped.

  5. Use the patch checklist to enable or disable which of the 131 slots the front-panel encoder scrolls past.

Factory Reset Wipes every user slot back to firmware defaults, including the 25 Magicstomp imports. It's the only way to bring those defaults onto a device that already has different settings saved.
05 — Good to know

Notes

Turning Knob 1 sounds smooth, not clicky

On the six delay-time/feedback patches, the read position inside the delay buffer glides toward wherever the knob is pointing rather than jumping there — this is what keeps a fast turn from producing a click or "zipper" artifact, especially with feedback recirculating.

Chorus and lead patches are unaffected by that

Knob 1's job is decided per patch, explicitly — by name, not by measuring the patch's own delay times — so nothing outside the six listed patches changed behavior when they were added.
